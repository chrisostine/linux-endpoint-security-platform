# Linux Endpoint Security Platform

An open-source Linux endpoint security and investigation platform
built with Python.

## Project status

Version: 0.1.0

Development status: Initial development.

## Planned capabilities

- System information collection
- Running process inspection
- Network connection inspection
- File integrity monitoring
- Basic suspicious activity detection
- Security investigation reports

## Technology

- Python
- Linux
- SQLite (planned)
- Git and GitHub

## Intended users

Individuals, security researchers, system administrators and
organisations.

## Security and usage

Use this software only on systems you own or are authorised to
monitor.
